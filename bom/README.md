# Manual-Dex bill of materials

Original BOM CSVs and the generated `BOM.md` are hardware-design records licensed under
[CERN-OHL-P-2.0](../hardware/LICENSE). See [licensing and reuse](../LICENSING.md) and
[third-party provenance](THIRD_PARTY.md).

- `robot_hand.csv` – every part of the robot hand assembly (`manual_dex_hand.step`)
- `glove.csv` – every part of the wearable glove assembly (`manual_dex_glove.step`)
- `BOM.md` – human-readable rendering, generated by `python tools/gen_bom_md.py`

ID scheme: `RH-`/`GL-` prefix, then `0xx` = printed part, `1xx` = bought part present in CAD,
`2xx` = bought part **not** in CAD (fasteners, wiring, electronics) – these rows carry `status=TODO`
until confirmed.
