# ESP32 glove firmware

The prototype uses an Adafruit HUZZAH32 ESP32 Feather to read eight Bourns 3382G rotary potentiometers. Firmware source, a verified pin map and the prototype’s sensor-to-servo calibration are pending release. To exercise the host software today, select the synthetic glove.

The simulated glove and host adapter are documented in the [LeRobot tutorial](../../lerobot/README.md).
For the physical glove, see the [proposed serial protocol](../../lerobot/PROTOCOL.md) and
[host-side calibration](../../lerobot/CALIBRATION.md).
